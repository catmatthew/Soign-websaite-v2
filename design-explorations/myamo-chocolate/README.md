# myamo chocolate ─ LP前半デザイン検討

`design.md` および `contents.md` に基づく、ランディングページ前半（ヒーロー＋数節）の
デザイン検討用サンプルです。方向性の異なる3案を並置しています。

| 案 | 呼称 | 第一画面の主役 | ファイル |
|---|---|---|---|
| A | 余白の雑誌 | 名前と写真の対（非対称二段組） | `concept-a-editorial.html` |
| B | 索引が主役 | 検索窓と国別索引 | `concept-b-index.html` |
| C | 写真が全面 | 全面写真に重ねた名前 | `concept-c-photographic.html` |

各案の設計意図は `concept-*.md` に記載しています。

## 見方

各HTMLは単体で完結しています。ブラウザで直接開いてください。
モーションはスクロールに連動するため、実機（できればiPhone）と
デスクトップの両方でご確認ください。

## 3案に共通する前提

### 範囲
ヒーローセクションから数節までです。各ファイル末尾に「ここまでが見本の範囲です」と
明示しています。チョコレートマップ一覧、店舗詳細、About、フッターは本開発フェーズの対象です。

### 写真
実素材が未確定のため、すべてプレースホルダ枠（グレージュの面）としています。
枠内に必要な縦横比と推奨解像度を表示し、HTMLコメントに `TODO 差し替え` を記載しています。
`design.md` が求める「写真主導」は、実写真の投入後に初めて成立します。
現時点の3案は、写真を置く位置・比率・面積の設計として評価してください。

### データ
掲載している店名・投稿はすべて `SAMPLE DATA` 表記のサンプルです。
`contents.md` の指示に従い、実在の店舗情報および実在URLは一切使用していません。
検索例の `Pierre Hermé` / `Paris` / `Tokyo` は、`contents.md` が検索例として
指定した文字列をそのまま用いています。

### 検索・絞り込み
検索窓とフィルタは見た目と操作感の確認用です。絞り込みチップは行ごとの単一選択として
状態遷移のみ動作します。実際の検索処理は本開発フェーズで実装します。

**プレースホルダの文言について。** `contents.md` が指定した
「ショコラティエ・ブランド・都市などで検索」は、560px未満の画面では途中で切れて
読めなくなります。そのため狭い画面では「ブランド・都市で検索」に短縮しています。
`design.md` のモバイル優先の方針を優先した判断です。短縮後の文言についてご確認ください。

### 技術
- 単体HTML／CSS／JavaScript。CSSフレームワークは未使用です。
- アニメーションは GSAP 3.12.5 + ScrollTrigger（cdnjs、バージョン固定）。
  `window.scroll` の監視は3案とも使用していません。
- Webフォントは Google Fonts を `<link>` で読み込んでいます。
  本番（Next.js）では `next/font` によるセルフホストに切り替えます。
- `prefers-reduced-motion: reduce` では全案とも演出を停止し、完成した静止ページになります。
- GSAP本体とScrollTriggerのどちらかでも読み込めなかった場合、演出を行わず静止ページとして描画します。
- さらに保険として、読み込みから3秒経っても初期状態のままの場合、画面内の要素を
  完成状態に戻します（回線や端末の事情で描画ループが進まない場合でも本文が消えません）。
- スクロールによる表示は一度きりです（`once: true`）。読み終えた内容が
  戻り操作で再び消えることはありません。

### 共通の意思決定
- 文字に `—`（emダッシュ）を使用していません。
- 「スクロール」を促す表示、装飾目的の番号ラベル、写真上に重ねるタグを使用していません。
- 角丸は案ごとに一つの基準に固定しています（A: 2px／B: 12px／C: 0）。
- 差し色は案ごとに一色のみ（カカオ系のブラウン）。全節で同一の色を使用します。
- 最小タップ領域 44×44px、コントラスト比 4.5:1 以上を全案で確保しています。

## 本番スタック

デザイン確定後、Next.js（App Router）＋ shadcn/ui へ移植します。
現時点の単体HTMLは、移植時の視覚仕様書として扱います。
`contents.md` の Shop Data Model はそのままコンテンツ層のスキーマとし、
チョコレートマップの検索・フィルタ・詳細ページを本開発フェーズで構築します。
