# Concept C 「熱」NETSU — 設計意図

## 設計思想
本案は、トップページ全体を「生豆が一杯になるまで」を描く一本の短編映画として構成しました。スクロールは再生バーであり、来訪者は読むのではなく、通過することでブランドを理解します。生 → 焙 → 挽 → 抽という四つの場面をビューポート全面に固定し、進行度に連動して映像・色・文字が同時に変化します。演出を取り去ると内容が成立しない、すなわちモーションそのものが設計である、という前提に立っています。

## 配色
単一の暗いキャンバス上で、焙煎の進行に従って色温度のみが推移します。基調は炭黒 `#050706`、生豆の深緑 `#16241A` / `#2C4430` / `#6B8A68`。唯一のアクセントは熾火のオレンジ `#C0562A`（強調時 `#E2853F`）で、CTA・工程番号・焙煎曲線に限定使用します。焙煎後の褐色 `#3A2317` / `#8A6449` を経て、最終場面では冷めていくクリーム `#EDE6D8` / `#CFC3AE` に収束。色数を五系統に限定し、蛍光色・グラスモーフィズムは一切使用していません。

## タイポグラフィ
すべて Google Fonts より実装。
- **Zen Old Mincho** — 見出し・場面タイトル・価格。映画のタイトルカードとしての役割を担い、和の明朝でありながら大きく組んでも硬質に見える点を採用理由としました。
- **Zen Kaku Gothic New** — 本文・商品説明・ボタン。長文の可読性と、明朝との明確な役割分離を担保します。
- **Jost** — ラテン系の小見出し、番号、数値、UI ラベル。広いトラッキングの大文字組みで、欧州的な精度感を与えます。

## レイアウト原則
横組みの静的グリッドは用いず、全画面の「フレーム」を積層させる構造です。巨大な漢字（生・焙・挽・抽）を最背面に置き、本文との視差で奥行きを作ります。商品部分も同じ文法を保ち、ロットを横方向にパンする一続きのリールとして提示。1480px で内容を抑え、左右余白は `clamp(16px, 5.2vw, 84px)` を全断面で共有します。

## モーション設計
GSAP 3.12.5 / ScrollTrigger による pin + scrub。変化は `transform` と `opacity`、および単一 canvas への描画に限定し、粒子は最大 110、DPR は 1.75 で上限を設けています。イージングは `none` と `power2/3.out` のみで、弾性・跳ね返りは使用しません。720px 以下では固定を解除し、各場面を順に読む構成へ切り替えます。`prefers-reduced-motion` では全場面を静的に展開し、情報量を損なわない読み物として成立させています。

## 向く場面・向かない場面
向くのは、ブランドの世界観を初回接触で伝えたい旗艦ページ、季節ごとの特集、ギフト期の訴求です。一方、在庫一覧・検索・比較購買といった反復利用の導線、低速回線や旧端末が主となる環境、頻繁な商品差し替えを前提とする運用には適しません。回遊用の一覧ページは別テンプレートで運用する前提を推奨します。
