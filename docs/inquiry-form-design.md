## 優先度の見かた

| 優先度 | 意味 | フォーム上の扱い |
|---|---|---|
| **A** | 返信・提案ができなくなる項目 | **必須** |
| **B** | 提案の精度が上がる項目 | 任意（推奨） |
| **C** | あれば助かるが、初日に聞ける項目 | 任意（後回し可） |

## 5. Googleフォームの制約（作るときの注意）

| 制約 | 対処 |
|---|---|
| 質問を条件で出し分けることはできない（セクション単位のみ） | 業態ごとにセクションを分け、各セクションの終わりを「S8へ移動」にする |
| 組み込みの「その他」は、分岐先を指定できない | 分岐の質問（1-8）では、通常の選択肢として「その他」を作る |
| 分岐の元にできるのは、ラジオボタンとプルダウンのみ | 1-8 をラジオボタンにする |
| メールアドレスの入力ミスは検知できない（確認入力が作れない） | 届かない場合は電話で補う。1-3 のヒントで注意を促す |
| 回答者の離脱は、Googleフォームでは見えない | 回答数とスプレッドシートの未入力率で判断する |
