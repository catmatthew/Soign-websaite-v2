# Square 商品連携の運用

## 構成

LPに掲載する3商品は `data/products.json` に保持する。ビルド時にSquare APIを呼ばない。

```
Square カタログ ──(読み取りのみ)──▶ /update-products ──▶ data/products.json ──▶ ビルド ──▶ 公開
      ▲                                     ▲
      │                                     │
  商品の編集                           承認(必須)
  (Square管理画面)
```

### この構成を選んだ理由

| 判断 | 理由 |
|---|---|
| ビルド時API連携を行わない | アクセストークンの保管が不要。Square障害時もビルドが失敗しない。ビルド結果が再現可能 |
| データをリポジトリに置く | 差分がGit履歴に残り、いつ何が変わったか追跡できる |
| 更新は承認制 | 意図しない内容が公開されることがない |
| 週次で差分監視 | 「依頼を忘れる」という唯一の弱点を塞ぐ。通知のみで、自動公開はしない |

**Square APIの利用に金銭コストは発生しない。** Squareの収益は決済手数料であり、API呼び出しは課金対象外。

## 初期設定(Square管理画面での作業)

**この作業はSquare管理画面から行ってください。** 事故を避けるため、Square側のデータ変更はこちらでは行いません。

1. Square管理画面 → 商品 → カテゴリ
2. カテゴリを新規作成し、名前を **`LP掲載`** とする(表記ゆれ不可)
3. LPに載せたい商品3点を、このカテゴリに追加する
4. 完了後、チャットで「LP掲載カテゴリを作りました」と伝える

以降、掲載商品の入れ替えは**このカテゴリへの出し入れだけ**で完結します。

### カテゴリ設定前の動作

カテゴリが未作成のあいだは、`data/products.json` の `featured[].id` に書かれた3件を掲載する。現在の暫定選定:

| 商品 | 価格 | 選定理由 |
|---|---|---|
| CostaRica La Candellila / White Honey | ¥1,720 | 入りやすい価格帯・甘さ主体 |
| Ethiopia Yirgacheffe Aricha G1 / Washed | ¥1,810 | 華やかな酸・対照的な味づくり |
| Bolivia Kantutani Geisha / Anaerobic Natural | ¥4,320 | 最上位。技術の証明 |

価格と味の方向を分散させ、3点で幅が伝わる構成にしている。**この3点は2026-09-27に承認済み。**

価格はいずれも税込（150g）。

## 日常の運用

### 商品情報が変わったとき

チャットで `/update-products` と入力する(または「商品を更新して」と伝える)。

1. Squareから取得
2. **差分が表形式で提示される**
3. 承認する
4. 更新・コミット・プッシュ・自動デプロイ

承認するまで何も書き換わらない。

### 週次の差分監視

毎週月曜の朝に自動でSquareとの差分を確認する設定になっている。**差分があるときだけ通知する。** 通知が来ても自動では公開されないため、内容を確認してから承認する。

> **現在この監視は機能していません。** Routine（`trig_01C93AVGGa68Z6dZ2ptPHFqb`）にSquareコネクタが付与されておらず、起動してもSquareに接続できずに終了する。組織の設定上、コネクタの付与はチャットからは実行できない。claude.ai の Routines 画面から当該Routineを開き、Squareコネクタを追加する必要がある。それまでは `/update-products` の手動実行で運用する。

## 価格の税表記

Square側の消費税設定を確認しました。

| 項目 | 値 |
|---|---|
| 税 | Consumption TAX（`jp_consumption_tax`） |
| 税率 | 10.0% |
| 適用方式 | **`INCLUSIVE`（内税）** |

**したがってSquareの登録価格は税込です。LP上も税込で表示します。**

卸価格（¥4,500/kg〜）は**税別**で表記しています。消費者向け価格には総額表示義務があり税込が必須ですが、事業者間取引は対象外で、税別表記が商慣行として一般的なためです。同じ豆でも消費者向けと卸で表記の基準が異なる点は、卸ページ本文にも明記してあります。

## やらないこと

- Squareカタログへの書き込み(商品・価格・在庫の変更)
- 味の記述(`note_short`)の自動生成
- 承認を経ない公開
- リポジトリへのアクセストークン保存
